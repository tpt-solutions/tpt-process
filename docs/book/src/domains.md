# Domain Guide

The suite is organized into domains, each one a set of focused crates.

- **Thermodynamics** — property framework, cubic EOS, activity models,
  flash, and the open chemical databank.
- **Fluid flow** — pipe hydraulics, pumps, compressors, valves, and
  network solvers (Hardy Cross, Newton-Raphson, Linear Theory).
- **Heat transfer** — convection correlations, LMTD/ε-NTU exchangers,
  pinch analysis, fired equipment.
- **Separations** — distillation (FUG + McCabe-Thiele + MESH), absorption
  (Kremser), extraction, membranes, crystallization.
- **Reaction engineering** — rate laws, ideal reactors, catalyst models.
- **Simulation** — sequential-modular flowsheet solver with Wegstein
  acceleration, balances, optimization.
- **Applications** — HVAC psychrometrics, water treatment, hydrogen,
  pharma, refining.
- **Data & deliverables** — data store, PFD export (SVG/DOT/Mermaid),
  process economics.
