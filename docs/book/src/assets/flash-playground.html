Checking for the wasm module…

Build the wasm package to enable the demo. This page drives the real solvers through tpt-proc-wasm; it needs pkg/tpt_proc_wasm.js (and the .wasm beside it) in this file's directory. From the repository root:

rustup target add wasm32-unknown-unknown
cargo install wasm-pack
wasm-pack build --target web crates/core/tpt-proc-wasm
cp -r crates/core/tpt-proc-wasm/pkg docs/book/src/assets/pkg

The book build copies docs/book/src/assets/ verbatim, so after the copy (and a page reload over a web server — ES modules do not load from file://) the demo runs fully offline.
