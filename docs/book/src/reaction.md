# Reaction Engineering

- **Kinetics**: Arrhenius, power law, Langmuir-Hinshelwood
  (product-inhibited), Michaelis-Menten; van 't Hoff equilibrium.
- **Reactors**: CSTR (under-relaxed fixed point) and PFR (RK4 with
  co-integrated adiabatic temperature), both verified against analytic
  first-order conversions.
- **Catalysis**: Thiele modulus and effectiveness factors
  (slab/cylinder/sphere), deactivation models.
