## 1. Open Source Declaration

`tpt-process` is a fully open-source, MIT-licensed computational engine for **chemical and process engineering**: thermodynamics, fluid flow, heat transfer, separations, reaction engineering, and flowsheet simulation. Every crate, every property package, and every solver is freely available under MIT OR Apache-2.0.

### Why Fully Open Source for Process Engineering?

The chemical process simulation space is one of the most locked-down industries in engineering software:

1. **The Desktop Monopoly:** Aspen HYSYS, Aspen Plus, ChemCAD, PRO/II, and gPROMS cost $30k-$100k+ per seat. They are closed-source, Windows-only, and tightly coupled to proprietary thermodynamic databanks.
2. **The Scripting Trap:** Open-source alternatives (CoolProp, Cantera, DWSIM) are bound to C++, C#, or Python, making them too slow for real-time control and impossible to compile into standalone, browser-based tools.
3. **The Databank Ransom:** The real value in process simulators is the thermodynamic property databanks. Incumbents charge recurring licensing fees for access to data that should be a public good.

`tpt-process` breaks all three locks. It provides a pure-Rust, MIT-licensed thermodynamic property engine, flowsheet solver, and unit operation library. Because it compiles to WebAssembly, chemical engineers can run flash calculations, heat exchanger ratings, and distillation shortcuts directly in the browser or on edge controllers — with no desktop license and no cloud dependency.

```rust
        temperature: f64,
```

```rust
        // P = RT/(v-b) - a·α/(v² + 2bv - b²)
        let a = self.a_parameter(composition, temperature);
        let b = self.b_parameter(composition);
        let r = 8.314462618;
```

```rust
    pub fn pt_flash(
        &self,
        feed: &Composition,
        temperature: f64,
        pressure: f64,
    ) -> FlashResult {
        // 1. Calculate K-values from property package
        // 2. Solve Rachford-Rice for vapor fraction β
        // 3. Calculate liquid and vapor compositions
        // 4. Iterate until K-values converge
        
        let mut k_values = self.property_package.k_values(feed, temperature, pressure);
        let mut beta = self.initial_beta_estimate(feed, &k_values);
        
        for _ in 0..100 {
            // Solve Rachford-Rice: Σ z_i(K_i-1)/(1+β(K_i-1)) = 0
            beta = self.rachford_rice(feed, &k_values, beta);
            
            let (x, y) = self.phase_compositions(feed, &k_values, beta);
            let new_k = self.property_package.k_values(feed, temperature, pressure);
            
            if converged(&k_values, &new_k) {
                return FlashResult { /* ... */ };
            }
            k_values = new_k;
        }
        
        panic!("Flash calculation did not converge");
    }
    
    fn rachford_rice(
        &self,
        feed: &Composition,
        k_values: &[f64],
        beta_guess: f64,
    ) -> f64 {
        // Newton-Raphson on Rachford-Rice equation
        let mut beta = beta_guess;
        for _ in 0..50 {
            let mut f = 0.0;
            let mut df = 0.0;
            for (i, z_i) in feed.mole_fractions().enumerate() {
                let k_i = k_values[i];
                f += z_i * (k_i - 1.0) / (1.0 + beta * (k_i - 1.0));
                df -= z_i * (k_i - 1.0).powi(2) / (1.0 + beta * (k_i - 1.0)).powi(2);
            }
            let delta = f / df;
            beta -= delta;
            if delta.abs() < 1e-10 {
                break;
            }
        }
        beta.clamp(0.0, 1.0)
    }
```

```rust
pub struct PipeFlow {
    pub diameter: f64,              // m
    pub length: f64,                // m
    pub roughness: f64,             // m (absolute roughness)
    pub fluid: FluidProperties,
}

pub struct FluidProperties {
    pub density: f64,               // kg/m³
    pub viscosity: f64,             // Pa·s
}

impl PipeFlow {
    pub fn reynolds_number(&self, velocity: f64) -> f64 {
        // Re = ρ·v·D/μ
        self.fluid.density * velocity * self.diameter / self.fluid.viscosity
    }
    
    pub fn friction_factor(&self, velocity: f64) -> f64 {
        let re = self.reynolds_number(velocity);
        
        if re < 2300.0 {
            // Laminar: f = 64/Re
            64.0 / re
        } else {
            // Turbulent: Colebrook-White equation
            self.colebrook_white(re)
        }
    }
    
    fn colebrook_white(&self, re: f64) -> f64 {
        // 1/√f = -2·log10(ε/(3.7D) + 2.51/(Re·√f))
        // Solve iteratively (or use Swamee-Jain approximation)
        let rel_roughness = self.roughness / self.diameter;
        
        // Swamee-Jain explicit approximation
        let f = 0.25 / (rel_roughness / 3.7 + 5.74 / re.powf(0.9)).log10().powi(2);
        f
    }
    
    pub fn pressure_drop(&self, flow_rate: f64) -> f64 {
        // Darcy-Weisbach: ΔP = f·(L/D)·(ρ·v²/2)
        let area = std::f64::consts::PI * self.diameter.powi(2) / 4.0;
        let velocity = flow_rate / area;
        let f = self.friction_factor(velocity);
        
        f * (self.length / self.diameter) 
            * self.fluid.density * velocity.powi(2) / 2.0
    }
    
    pub fn pressure_drop_per_length(&self, flow_rate: f64) -> f64 {
        self.pressure_drop(flow_rate) / self.length
    }
}
```

```rust
    pub fn nusselt_number(
        &self,
        reynolds: f64,
        prandtl: f64,
    ) -> f64 {
        match (&self.geometry, &self.flow_regime) {
            (Geometry::PipeInternal, FlowRegime::Turbulent) => {
                // Dittus-Boelter: Nu = 0.023·Re^0.8·Pr^n
                0.023 * reynolds.powf(0.8) * prandtl.powf(0.4)
            }
            (Geometry::PipeInternal, FlowRegime::Laminar) => {
                // Constant: Nu = 3.66 (fully developed, constant T)
                3.66
            }
            (Geometry::FlatPlate, FlowRegime::Turbulent) => {
                // Nu = 0.037·Re^0.8·Pr^(1/3)
                0.037 * reynolds.powf(0.8) * prandtl.powf(1.0/3.0)
            }
            _ => unimplemented!(),
        }
    }

        &self,
        nusselt: f64,
        thermal_conductivity: f64,
        characteristic_length: f64,

        // h = Nu·k/L
```

```rust
    pub fouling_factors: FoulingFactors,
    pub configuration: FlowConfiguration,
}

    PlateAndFrame,
    DoublePipe,
    AirCooled,
    SpiralWound,
}

pub enum FlowConfiguration {
    CounterCurrent,
    CoCurrent,
    Crossflow,
    ShellTube { passes: u32 },
}

impl HeatExchanger {
    pub fn lmtd(
        &self,
        hot_in: f64,
        hot_out: f64,
        cold_in: f64,
        cold_out: f64,
    ) -> f64 {
        // Log Mean Temperature Difference
        let dt1 = hot_in - cold_out;
        let dt2 = hot_out - cold_in;
        
        if (dt1 - dt2).abs() < 1e-6 {
            dt1  // Avoid division by zero
        } else {
            (dt1 - dt2) / (dt1 / dt2).ln()
        }
    }
    
    pub fn duty_from_lmtd(
        &self,
        hot_in: f64,
        hot_out: f64,
        cold_in: f64,
        cold_out: f64,
        correction_factor: f64,
    ) -> f64 {
        // Q = U·A·LMTD·F
        let lmtd = self.lmtd(hot_in, hot_out, cold_in, cold_out);
        self.overall_coefficient * self.area * lmtd * correction_factor
    }
    
    pub fn ntu_effectiveness(
        &self,
        hot_capacity_rate: f64,     // m·cp (W/K)
        cold_capacity_rate: f64,
    ) -> NtuResult {
        // NTU = UA/C_min
        // ε = f(NTU, C_r)
        let c_min = hot_capacity_rate.min(cold_capacity_rate);
        let c_max = hot_capacity_rate.max(cold_capacity_rate);
        let c_r = c_min / c_max;
        let ntu = self.overall_coefficient * self.area / c_min;
        
        let effectiveness = match self.configuration {
            FlowConfiguration::CounterCurrent => {
                (1.0 - (-ntu * (1.0 - c_r)).exp()) 
                    / (1.0 - c_r * (-ntu * (1.0 - c_r)).exp())
            }
            FlowConfiguration::CoCurrent => {
                (1.0 - (-ntu * (1.0 + c_r)).exp()) / (1.0 + c_r)
            }
            _ => unimplemented!(),
        };
        
        NtuResult { ntu, effectiveness, capacity_ratio: c_r }
    }
    
    pub fn rate(

        hot_stream: &MaterialStream,
        cold_stream: &MaterialStream,
    ) -> RatingResult {

        hot_stream: &MaterialStream,
        cold_stream: &MaterialStream,
    ) -> SizingResult {
```

```rust
pub struct Reaction {

}

pub enum ReactionKinetics {
    Arrhenius {
        pre_exponential: f64,       // A
        activation_energy: f64,     // Ea (J/mol)
        reaction_order: HashMap<ComponentId, f64>,
    },
    PowerLaw {
        k: f64,
        orders: HashMap<ComponentId, f64>,
    },
    LangmuirHinshelwood {
        adsorption_constants: HashMap<ComponentId, f64>,
        rate_constant: f64,
    },
    MichaelisMenten {
        v_max: f64,
        k_m: f64,
    },
}

impl ReactionKinetics {
    pub fn rate_constant(&self, temperature: f64) -> f64 {
        match self {
            ReactionKinetics::Arrhenius { pre_exponential, activation_energy, .. } => {
                // k = A·exp(-Ea/RT)
                pre_exponential * (-activation_energy / (8.314 * temperature)).exp()
            }
            ReactionKinetics::PowerLaw { k, .. } => *k,
            _ => unimplemented!(),
        }
    }
    
    pub fn reaction_rate(
        &self,
        composition: &Composition,
        temperature: f64,
    ) -> f64 {
        let k = self.rate_constant(temperature);
        // r = k · Π C_i^n_i
        match self {
            ReactionKinetics::Arrhenius { reaction_order, .. } => {
                let mut rate = k;
                for (comp, order) in reaction_order {
                    rate *= composition.concentration(comp).powf(*order);
                }
                rate
            }
            _ => unimplemented!(),
        }
    }
}
```

## 14. Summary

`tpt-process` is a fully open-source, MIT-licensed, pure-Rust computational engine for chemical and process engineering:

- **Thermodynamics** — Equations of state, activity models, phase equilibrium
- **Fluid Flow** — Pipe networks, pumps, compressors, valves
- **Heat Transfer** — Convection, heat exchangers, pinch analysis
- **Separations** — Distillation, absorption, extraction, membranes
- **Reaction Engineering** — Kinetics, reactors, catalysis
- **Process Simulation** — Flowsheet solving, mass/energy balance
- **Applications** — HVAC, water treatment, refining, hydrogen, pharma

All crates maintain the strict MIT chain, leverage the TPT substrates (`tpt-math`, `tpt-engineering`, `tpt-science`), and compile to WebAssembly for browser-based process design and edge control.

No proprietary cores. No GPL traps. No databank ransom. Just open source.
